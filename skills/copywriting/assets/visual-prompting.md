# VISUAL PROMPTING

> **Version 0.1** | 2026-10-15

An on-brand image prompt for a piece that needs a picture. **The prompt is the deliverable.** This skill writes the prompt; it does not make images. The user pastes the prompt into their own image tool – say so in the line that hands it over.

---

## WHAT A PROMPT CARRIES

| Part | What to write |
|---|---|
| **Subject and scene** | what is in the picture, with one clear focal point, tied to the piece's main idea rather than a literal picture of its title |
| **Style** | the look the brand's design rules name – photographic, flat illustration, 3D, line art – and its rendering |
| **Palette** | the brand's colours by name and hex value, and which one leads |
| **Composition** | framing, the focal point's place, empty space where text will sit, the aspect ratio for the channel |
| **Mood** | the feeling it should leave, matched to the piece's tone |
| **Brand elements** | any visual signature the design rules name, used once and lightly |
| **Avoid** | what must not appear: what the brand forbids, stock clichés (handshakes, light bulbs, people pointing at screens), words inside the image unless the user asks for them, logos |

---

## TEMPLATE

```
[Subject and scene], [style], [composition], aspect ratio [ratio].
Palette: [colour name and hex], [colour name and hex] – [lead colour] leads.
Mood: [feeling].
Brand elements: [signature element, if any].
Avoid: [exclusions].
```

---

## WITHOUT BRAND DESIGN RULES

When the context holds none: ask for the brand's main colours and the look they use, or write a neutral prompt and say plainly that it is unbranded.

---

## HANDING IT OVER

- One line: this is a prompt to paste into the user's image tool.
- One variant with a different composition, so they have a choice.
- Any text meant to sit on the image, given separately as copy for their design tool.
